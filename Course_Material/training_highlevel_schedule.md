# Training High-Level Schedule

## Week 1 — Introduction to Programming

- **Session 1 (1.5 hrs):**
  - Overview of CCC: contest format (5 questions, 3 hours) and participation goals
  - Install Python and an IDE
  - Write the first program using `print()` and basic syntax
- **Session 2 (1.5 hrs):**
  - Explore variables and data types (`int`, `float`, `str`, `bool`)
  - Review basic math operators (`+`, `-`, `*`, `/`, `%`)
  - Work through area calculations and simple arithmetic (J1-style exercises)
- **Homework / Practice:**
  - Write three to five short programs that use `print()`
  - Read the Python introduction on python.org
  - Solve one or two easy problems from Code.org

## Week 2 — Input / Output & Basic Logic

- **Session 1 (1.5 hrs):**
  - Gather user input with `input()`
  - Convert between strings and numbers using `int()` and `str()`
  - Format output with f-strings
- **Session 2 (1.5 hrs):**
  - Build conditional logic with `if`/`elif`/`else`
  - Practise comparison operators (`==`, `>`, `<`, `>=`, `<=`)
  - Solve even/odd checks and other decision problems
- **Homework / Practice:**
  - Code five programs that mix input and conditionals (e.g., age checker)
  - Review basic I/O in CCC Junior sample problems

## Week 3 — Loops Basics

- **Session 1 (1.5 hrs):**
  - Write `while` loops and avoid infinite loops
  - Use counters in loop bodies
- **Session 2 (1.5 hrs):**
  - Iterate with `for` loops and `range()`
  - Compute sums and averages with loops
- **Homework / Practice:**
  - Print patterns such as rows of stars
  - Sum the first *N* numbers
  - Attempt CCC 2010 J1 or another counting problem

## Week 4 — Nested Loops & Strings

- **Session 1 (1.5 hrs):**
  - Combine loops to handle grids and pattern generation
  - Review string indexing, slicing, and `len()`
- **Session 2 (1.5 hrs):**
  - Practise string methods (`upper()`, `find()`, `replace()`)
  - Reverse strings and perform text manipulation tasks
  - Simulate CCC J3/J4 distance-table style problems
- **Homework / Practice:**
  - Count vowels and check palindromes
  - Complete three or four exercises plus one CCC string problem

## Week 5 — Lists & Dictionaries

- **Session 1 (1.5 hrs):**
  - Create, index, append, and remove list items
  - Introduce dictionaries and key–value lookups
- **Session 2 (1.5 hrs):**
  - Traverse lists to find sums, maxima, and minima
  - Use `sorted()` for simple ordering
  - Update dictionaries and practise frequency counts
- **Homework / Practice:**
  - Average a set of grades and detect duplicates
  - Solve CCC-style problems that process lists of numbers

## Week 6 — Functions

- **Session 1 (1.5 hrs):**
  - Define reusable functions with parameters and returns
  - Discuss modular problem solving
- **Session 2 (1.5 hrs):**
  - Build functions that include loops and conditionals (e.g., factorial)
  - Cover the basics of variable scope
- **Homework / Practice:**
  - Implement five practice functions such as `is_prime`
  - Refactor Week 3 solutions to use helper functions

## Week 7 — 2D Lists / Arrays

- **Session 1 (1.5 hrs):**
  - Construct two-dimensional lists and access elements
  - Traverse grids with nested loops
- **Session 2 (1.5 hrs):**
  - Sum rows and columns and simulate grid-based problems
  - Revisit CCC J2/J3 simulations with 2D data
- **Homework / Practice:**
  - Build a tic-tac-toe board or other pattern grids
  - Complete a CCC example that processes grid input

## Week 8 — Mid-Course Review & Simple Algorithms

- **Session 1 (1.5 hrs):**
  - Review Weeks 1–7 and administer a short quiz
  - Introduce brute-force search strategies
  - Discuss debugging basics and acceptable input sizes (e.g., `N ≤ 100`)
- **Session 2 (1.5 hrs):**
  - Count frequencies in lists and strings
  - Explore basic time-complexity ideas
- **Homework / Practice:**
  - Mix review activities covering all topics so far
  - Attempt a full CCC Junior set such as 2015 J1–J2

## Week 9 — Advanced Conditionals & Loops

- **Session 1 (1.5 hrs):**
  - Handle complex nested `if`/`else` logic
  - Apply `break` and `continue`
- **Session 2 (1.5 hrs):**
  - Build conditional loops for small games (e.g., number guessing)
- **Homework / Practice:**
  - Implement a number guessing game
  - Practise CCC problems that involve layered conditions

## Week 10 — String Algorithms

- **Session 1 (1.5 hrs):**
  - Use `split()` and `join()` for parsing
  - Review palindromes and anagrams
  - Introduce regular expressions when appropriate
- **Session 2 (1.5 hrs):**
  - Decode messages and perform word counts
  - Build cumulative sum tables from strings
- **Homework / Practice:**
  - Tackle string-heavy CCC questions such as 2018 J3

## Week 11 — List Algorithms

- **Session 1 (1.5 hrs):**
  - Discuss sorting concepts and implement bubble sort by hand
  - Introduce binary search on sorted data
- **Session 2 (1.5 hrs):**
  - Explore sub-lists, merging techniques, and why sorting improves solutions
- **Homework / Practice:**
  - Implement a simple sort
  - Practise list-processing tasks from CCC 2020 J2 or similar

## Week 12 — Functions & Modularity

- **Session 1 (1.5 hrs):**
  - Introduce recursion with factorial and Fibonacci examples
  - Present the bottom-up dynamic programming concept at a high level
- **Session 2 (1.5 hrs):**
  - Break larger problems into helper functions
  - Practise debugging within modular code
- **Homework / Practice:**
  - Complete two or three recursion exercises
  - Refactor previous homework into well-structured modules

## Week 13 — 2D Arrays & Grids

- **Session 1 (1.5 hrs):**
  - Solve advanced 2D patterns including path counting and matrix operations
- **Session 2 (1.5 hrs):**
  - Simulate mazes and board-style games
- **Homework / Practice:**
  - Attempt grid-based CCC challenges such as 2016 J4
  - Build a small grid-based game or simulation

## Week 14 — Algorithm Design

- **Session 1 (1.5 hrs):**
  - Compare brute-force and greedy strategies
  - Revisit common patterns such as accumulation and tracking min/max values
- **Session 2 (1.5 hrs):**
  - Run group problem-solving sessions to design CCC-style questions
- **Homework / Practice:**
  - Solve three or four algorithmic exercises
  - Attempt CCC 2021 J1–J3

## Week 15 — Efficiency & Optimization

- **Session 1 (1.5 hrs):**
  - Examine CCC time limits and how loops affect runtime
  - Introduce Big-O notation without heavy math
- **Session 2 (1.5 hrs):**
  - Optimise prior solutions by spotting inefficient sections of code
- **Homework / Practice:**
  - Rewrite a slow loop for better performance
  - Practise timed coding sessions (two problems in one hour)

## Week 16 — Full Problem-Solving Practice

- **Session 1 (1.5 hrs):**
  - Walk through a full CCC Junior set (e.g., 2022)
  - Discuss contest strategy and time management
- **Session 2 (1.5 hrs):**
  - Work independently on J1–J2 problems from another year and review solutions
- **Homework / Practice:**
  - Finish any unsolved problems
  - Submit solutions to the CCC grader where available

## Week 17 — Mock Contest 1

- **Session 1 (1.5 hrs):**
  - Run a simulated contest with three problems at the J1–J3 level
- **Session 2 (1.5 hrs):**
  - Debrief common mistakes and share time-management tips
- **Homework / Practice:**
  - Complete the mock contest and review solutions
  - Attempt J4 and J5 equivalents for stretch practice

## Week 18 — Advanced Topics & Edge Cases

- **Session 1 (1.5 hrs):**
  - Revisit recursion with tree-based thinking
  - Discuss handling edge cases such as large inputs or empty data sets
- **Session 2 (1.5 hrs):**
  - Introduce basic file I/O for larger input cases
- **Homework / Practice:**
  - Practise recursion drills
  - Solve CCC problems with tricky edge cases (e.g., 2019 J5)

## Week 19 — Mock Contest 2

- **Session 1 (1.5 hrs):**
  - Hold a full mock contest with three mixed-difficulty questions
- **Session 2 (1.5 hrs):**
  - Review contest strategy, partial scoring, and careful problem reading
- **Homework / Practice:**
  - Analyse mock results and note improvements
  - Solve one or two harder past problems for additional challenge
