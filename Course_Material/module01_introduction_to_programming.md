Sample Question
- Prompt: Write a program that prints a welcome message for the CCC and displays the number of days remaining until contest day (use 30 days as the example).
- Solution:
```python
print("Welcome to the Canadian Computing Competition training!")
days_remaining = 30
print("Only", days_remaining, "days left until contest day. Let's get ready!")
```

Practice Challenge
- Prompt: Ask the user for their name and favorite number, then print a message such as `Hello Sara! Your lucky number is 7.`.
- Solution:
```python
name = input("Enter your name: ")
favorite_number = input("Enter your favorite number: ")
print("Hello " + name + "! Your lucky number is " + favorite_number + ".")
```
